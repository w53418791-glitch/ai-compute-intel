2026-01-15 新政：「对华禁运/逐案审查/推定拒绝」仅适用于美国及受 EAR 管辖的芯片（NVIDIA、AMD 等）；中国自研芯片（华为/寒武纪/壁仞/摩尔线程）标注为「参数落入 3A090 范围」，不适用美国出口许可。紫色虚线 = TPP 21K 上限（其下为逐案审查，其上为推定拒绝），红色虚线圈 = 推定拒绝。
口径：TPP = INT8 稠密算力 × 8 位（稠密值）；PD = TPP ÷ 芯片面积（mm²）；两轴均为对数刻度。
政策归属（重要）：「对华禁运 / 推定拒绝 / 逐案审查」仅针对美国及受 EAR 管辖的芯片（NVIDIA、AMD 等）。中国自研芯片（华为 / 寒武纪 / 壁仞 / 摩尔线程）不适用美国出口许可，图中其落点表示「性能参数落入 3A090 管制基准」（美方评估其性能等级的参照，也受美国供应链 / EDA / 设备等限制）。
2026-01-15 新政（FR 2026-00789 / 91 FR 1684）：3A090.a 中 TPP<21,000 且 总DRAM带宽<6,500GB/s 的美系芯片（H200、MI325X 等）从美国直接出口至中国/澳门改按逐案审查（紫线以下）；TPP≥21,000 或 带宽≥6,500GB/s（如 Blackwell B 系）以及再出口/转口仍为推定拒绝（紫线以上，红圈标注）。
注：H20（TPP≈2368 / PD≈2.91）为 NVIDIA 专为中国压降算力版本，落在 3A090 参数范围外、可对华销售；MI325X 与 MI300X 同算力（TPP≈20,856），为逐案审查规则点名型号。标注「规划」的芯片参数为官方路线图/估算。实际以 BIS 认定为准。
